# 人间续章

手机优先的现代文字人生模拟器。静态 HTML、CSS、原生 JavaScript ES modules，无外部依赖。

## 产品约定

- 出生于随机中国当代风格家庭；社会与科技框架保持稳定。
- 每回合一个月，四次行动；玩家手动安排，暂停期间不推进。
- 人生阶段：婴幼儿、幼儿园、小学、初中、高中/职校、大学/专科/技能就业、成年、退休。
- 人物性格、天赋、外貌、独立生活状态与有因果影响的关系记忆。
- 家人会独立成长、工作、结婚和育儿；未成年子女成年后可接班。
- 接班不转移资产；赠与与身后结算分别处理，避免复制财产。
- 资产包含存款、债务、住房、小店、家具；身后资产折现偿债后分配。
- 五个页面：生活、人物、成长、资产、家族。
- 三个当前浏览器本地存档，自动保存、JSON 导出与导入。无云端同步。

## 文件

- `engine.js`：可独立运行的确定性模拟引擎与事件库。
- `app.js`：UI、交互、本地存档、可选 WebMCP 注册。
- `style.css`：响应式布局、轻动画与减少动态效果支持。
- `index.html`：入口，内联 favicon。

## 验证

运行 `node tests/simulation.mjs` 验证出生到死亡、接班、资产结算、存档恢复与错误路径。
运行 `node tests/interface.mjs` 验证五个页面的 DOM 合约与主要点击路径。

已通过三个确定性完整生命周期，以及婚育到第二代接班路径。当前环境未提供适用于静态站点的受支持浏览器预览，因此没有实际设备视觉验收。WebMCP 仅在支持的浏览器中注册；未进行真实 WebMCP 上下文验收。

## 第一版范围

职业、事件、装修与小店为简化版本，后续可扩充内容数量与更细的互动。婚育采用迎接子女的抽象流程；大学、退休、婚育年龄、贷款与继承都是游戏规则，并非对现实制度的描述。

存档随机数种子随进度保存。页面不加载外部字体、图片、AI 服务或分析脚本。
