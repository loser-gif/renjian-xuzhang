# 人间续章

手机优先的现代文字人生模拟器。静态 HTML、CSS、原生 JavaScript ES modules，无外部依赖。

公开网址：https://loser-gif.github.io/renjian-xuzhang/

## v0.3：重新设计开局与成年前体验

- 主菜单支持继续、新建、三个本地存档与玩法说明。打开菜单不自动创建人生。
- 创建角色：填写 1—12 字姓名或随机名字；六种特质中选两种，实时预览初始属性与特殊加成。确认开局才写入目标存档，替换前需要确认。
- 四项核心属性：智力、运气、颜值、心情，范围 0—100。智力影响学习与求职，运气影响成长幸运事件、求职与经营，颜值影响约会关系收益，心情随生活变化。
- 0—18 岁：18 个独立成长事件，每次选择推进一岁并展示实际属性变化；成年时的属性作为后续生活起点。
- 18 岁：选择参加考试或直接进入社会。考试为 15 道简单单选题（成语、常识、简单数学等），每题 50 分，总分 750；提交后显示解析，不能重复得分。题目与选项顺序随机一次并存档，无计时。
- 成绩达到 650 / 500 / 350 / 150 分，可分别申请星河大学、江城大学、清禾应用大学、海城职业学院；也可选择较低门槛的学校或暂不入学。学校和分数线均为游戏设定。
- 本科四年、专科三年，与原有毕业和成年生活系统衔接。成年后每月四次行动，含可跳过的首月引导。
- 旧版成年存档直接继续；未成年存档保留姓名、属性、关系与已有经历，从当前年龄接入剩余成长事件；已触发的旧事件可先完成。本月未执行安排因改为年度成长而清空。

## 持续的人生与家族

现代中国风格的架空家庭背景，社会框架稳定。成年后经营学习、工作、关系和资产；家人具有性格、共同记忆与独立生活。子女成年后可接班，上一代继续生活。

接班不转移资产；赠与、身后资产折现偿债及继承分别结算。三个档案保存在当前浏览器，支持 JSON 导出、导入，无云端同步。关闭页面不会推进时间。

## 文件

- `opening.js`：角色特质、18 个成长事件、考试题库、大学申请、成长存档验证及旧档接入。
- `engine.js`：成年模拟、关系、家族、资产与确定性随机数。兼容旧版内部属性字段（ability = 智力，appearance = 颜值）；体力和健康等保留为成年模拟的辅助状态。
- `app.js`：菜单、创建角色、成长/考试/申请界面、新手引导与本地存档。
- `style.css`：响应式布局、竖屏适配与减少动态效果支持。
- `index.html`：无外部字体、图片、AI 或分析服务的静态入口。

## 验证

运行 `npm test`。覆盖名字与特质、18 次选择、全部成绩档位、大学申请限制、考试去重与续答、放弃考试、毕业、旧档接入、档案隔离、五个页面、关系、接班与多个完整生命周期。

职业、大学、退休、婚育、经营与继承均为游戏化简化，不对应现实制度。
